# Sverify — изтегляне

Sverify (по-рано Proofcheck) сравнява оригинала (PDF, скан, снимка или Word) с готовия превод в Word и показва
съмнителните места: числа, дати, имена, термини, оформление и брой страници.
Всичко се проверява **локално на компютъра**: документите не се качват никъде.

**[⬇ Изтегли Sverify за Windows](https://github.com/kirilbuyukliyski6-netizen/sverify-download/releases/latest/download/Sverify.msi)**

Инструкции и въпроси: https://sverify.vercel.app

1. Отворете изтегления файл **Sverify.msi**.
2. Отметнете „Приемам условията“ и натиснете „Инсталирай“.
3. Sverify е на работния плот и в менюто „Старт“.

Ако Windows покаже „Windows защитава компютъра ви“: **Още информация** → **Изпълни въпреки това**.

Деинсталиране: Настройки → Приложения → Sverify → Деинсталиране.
